### 6.6 Shard command contract (fixes the "same settings on every machine" risk)

Every shard owner must run exactly this, changing only `--shard i/4`, `--dtype` and `--device`:

```bash
python scripts/precompute_embeddings.py --manifest manifests/ucf_test.csv --shard i/4 --fps 1 \
  --model google/siglip2-base-patch16-384 --model openai/clip-vit-base-patch32
```

- Same models, same `--fps 1`, same manifest on every machine. The cache key is model + video_id + fps, so a different fps silently makes a shard unusable.
- `--dtype float16` on the 3050s, `float32` on the 1060. The cache is stored in fp16 either way.
- Copy the resulting `cache/embeddings/*.npy` files into one folder. Merging shards is only copying files, never editing code.
- A video that fails is reported and skipped; rerun the same command and only the missing ones are done.
